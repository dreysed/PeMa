# PeMa — Персональный менеджер тренировок

Творческая работа студентов группы РИС-25-1Б — Пархоменко Романа и Мехоношина Антона.  
Тема: Разработка автоматизированного рабочего места спортивного тренера.

Десктопное приложение для планирования и отслеживания тренировок. Тренер создаёт планы, спортсмены выполняют их и фиксируют результаты.

Стек: **Qt 6 / QML** + **Python FastAPI** (бэкенд задеплоен на Amvera).

---

## Возможности

- **Календарь** — месячная сетка тренировок, добавление / редактирование / удаление
- **Роли** — тренер создаёт планы для спортсменов; спортсмен видит только свой календарь
- **Аналитика** — суммарная дистанция, темп, серия дней, графики по неделям / месяцам, процент выполнения
- **Цели** — соревновательные или объёмные цели с автоматическим отслеживанием прогресса
- **Маршруты** — генерация круговых маршрутов по дистанции, рисование от руки на OSM-карте, редактирование и экспорт GPX
- **Импорт с часов** — загрузка `.gpx` или `.fit` → ЧСС, дистанция, темп, набор высоты заполняются автоматически
- **Синхронизация со Strava** — подключение по OAuth2, импорт всей истории активностей
- **Шаблоны** — сохранение и повторное использование структур тренировок
- **Карта боли** — кликабельный силуэт тела для отметки болевых ощущений
- **ИИ-тренер** — ассистент на базе Cerebras, с учётом роли
- **Темы** — тёмная / светлая / системная

## Быстрый старт

Qt, Python и компиляторы не нужны. Скачай лаунчер для своей ОС и запусти.  
При каждом запуске он проверяет обновления на GitHub и устанавливает их автоматически.

### macOS

1. Скачай **[PeMa.command](https://raw.githubusercontent.com/dreysed/PeMa/final/PeMa.command)**
2. Открой Терминал, выполни один раз чтобы разрешить запуск:
   ```bash
   chmod +x ~/Downloads/PeMa.command
   ```
3. Дважды кликни `PeMa.command` в Finder — готово.

При первом запуске скачается приложение (~100 МБ). Следующие запуски — мгновенные, кроме случаев когда есть обновление.

### Linux

1. Скачай **[PeMa.sh](https://raw.githubusercontent.com/dreysed/PeMa/final/PeMa.sh)**
2. Сделай исполняемым и запусти:
   ```bash
   chmod +x PeMa.sh
   ./PeMa.sh
   ```

### Windows

1. Скачай **[PeMa.bat](https://raw.githubusercontent.com/dreysed/PeMa/final/PeMa.bat)**
2. Дважды кликни — приложение скачается, установится без диалогов и откроется.

## Настройка Strava

1. Зайди на [strava.com/settings/api](https://www.strava.com/settings/api) → создай приложение  
   В поле **Authorization Callback Domain** укажи `localhost`
2. В PeMa открой **Настройки → Strava**, введи Client ID и Client Secret
3. Нажми **Подключить Strava** — откроется браузер для авторизации
4. После редиректа нажми **Синхронизировать** — вся история импортируется

## Импорт с часов / GPS

В шапке приложения нажми **📥 Импорт**, выбери файл `.gpx` или `.fit`, экспортированный из:

- **Garmin Connect** — Активности → активность → ··· → Экспортировать оригинал
- **Apple Watch** — Здоровье → Поделиться → Экспортировать (zip содержит `.gpx`)
- **Strava** — Активность → ··· → Экспортировать GPX
- **Polar / Suunto / Coros** — экспорт из приложения или веб-портала

Тренировка создаётся автоматически со статусом «выполнено», все метрики заполняются.
